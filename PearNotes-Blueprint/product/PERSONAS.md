# Personas, jobs-to-be-done, and stories

## Persona A — Solo exam learner (launch)

**Context:** Many disconnected PDFs/text notes, limited study time, needs structured progression. **Job:** "When I receive messy material, help me turn it into manageable activities and tell me what to do next without losing my ability to explore." **Success:** first lesson within one session; can find exact source; can reopen same state; sees targeted practice after errors. **Failure:** AI guesses syllabus or floods the canvas with dense cards.

## Persona B — Collaborative study pair (launch)

**Context:** Friends preparing for the same test from different sources. **Job:** "Let us work on the same concepts, point at the same diagrams, talk in context, and keep useful explanations." **Success:** invites work, two simultaneous views stay in sync, private sources remain private. **Failure:** chat drowns out activity, one person's answers overwrite another's.

## Persona C — Self-directed lifelong learner (next)

**Context:** Books, notes, websites, lectures collected over months. **Job:** "Make my growing knowledge library useful for active practice." **Success:** imports expand rather than reset subjects; concepts become discoverable; revision resurfaces old learning.

## Persona D — Student project team (later)

**Context:** Shared research and deliverables. **Job:** "Give our work a home where tasks, discussions and resources stay contextual." **Success:** group HQ, project room, roles, collaborative boards, decisions archived.

## Persona E — Educator (later)

**Context:** Responsible for lesson correctness and feedback. **Job:** "Review and publish interactive learning spaces, assign them, and inspect aggregated progress with appropriate privacy." **Success:** approval workflow, curriculum versioning, independent checks. **Failure:** unreviewed AI content presented as authoritative.

## Key user stories

| ID | As a user I want to… | Acceptance cue |
|---|---|---|
| U01 | create my first subject from a dashed plus | No seeded subjects on fresh account |
| U02 | upload two mixed PDFs | Reviewable subject proposals with source assignment |
| U03 | create an empty subject manually | Persisted empty subject, no fictitious syllabus |
| U04 | choose my subject avatar | Selection ring, saved identity and color |
| U05 | enter my learning path from subject picker | Right half-screen drawer, dimmed home, accessible close |
| U06 | pick a unit and enter lesson | Canvas loads right lesson, resources, objective |
| U07 | ask "explain this" on selected object | Tutor uses selected widget and grounded source |
| U08 | retry after a misconception | Progress + focused alternative task, no false mastery |
| U09 | return days later | Prior work, completed nodes and session state retained |
| U10 | study with a friend | Chat/cursors synchronized, individual grades isolated |
| U11 | earn a trophy | One server-confirmed award, no duplicate credit on refresh |
| U12 | share one learning artifact into group | Explicit scoped publication only |

## Research plan

Before broad rollout, interview 5–8 diverse students, run comprehension usability tests for drawer→canvas transitions, compare AI-generated activities with instructor-authored answers, and recruit users with accessibility needs. Avoid asserting educational improvement without measuring it.
