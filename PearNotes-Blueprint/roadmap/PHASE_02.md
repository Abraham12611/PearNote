# Phase 02 — Complete the core learning platform

**Suggested horizon:** initial post-hackathon alpha, approximately 2–6 weeks depending on team/capacity. **Goal:** support sustained multi-subject study, not just a short demonstration.

## 02.1 Full Subject Manager

- Rename, archive, restore, merge and split subjects; editable avatars, color and objectives.
- Add material to an existing subject, diff against present concepts and propose updated curriculum version.
- Preserve previous attempts/mastery/notes through schema-safe curriculum update.

**Exit:** update sources without losing completed lessons or prior study history.

## 02.2 Study Library

- All source files in an owner-scoped searchable library; filters/tags/folders, source previews, highlights and annotations.
- Many-to-many associations with subjects and lessons; show `used in` backlinks.
- Search exact keywords and semantically related source segments with permission-scoped retrieval.

**Exit:** students can find source paragraph→lesson and lesson→source in two actions.

## 02.3 Lesson UX completeness

- Accurate resume, save viewport and draft state, personal note editor, bookmarks, undo/redo for canvas changes, accessible linear activity view.
- Better focused reading, keyboard support, source navigation, mobile layout and reduced motion.
- Canonical empty/error/loading states; no lost responses on reconnect.

**Exit:** students can reliably study multiple sessions on desktop and mobile.

## 02.4 Widget expansion A

- Flashcard Deck, matching, sequencing, fill-in-the-blank, basic Concept Map and Formula/Worked Example cards.
- Typed schemas, default art, accessibility alternative, source ref and assessment outcome for each.

**Exit:** each widget passes renderer/schema and scoring fixture tests.

## 02.5 Profile, settings and Home personalization

- Profile avatar/name and personal trophy shelf; privacy, preferences, accessibility, timezone, notifications, daily goals.
- Pinned home desk cards, upcoming reviews, recent work and groups; user can reorder/hide widgets.

**Exit:** personalized Home persists per user, empty state remains friendly.

## 02.6 Product analytics and support

- Activation, correct learning outcome, return rate, import fail and model cost dashboards; error reporting and source recovery help.
- Usability testing with real students, evaluate first lesson time and content correctness.

**Exit:** alpha release with quality targets and top issues prioritized.

**Deferred:** broad media ingestion, leagues, paid plans, public marketplace, formal classroom administration.
