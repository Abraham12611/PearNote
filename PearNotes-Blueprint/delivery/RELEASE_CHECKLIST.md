# Final engineering, demo and submission checklist

## Repository and license

- [ ] Fork pinned from selected `main` SHA and origin documented
- [ ] MIT copyright retained; media/font/artwork rights audited
- [ ] New PearNotes package, metadata, domain, environment, deployment IDs
- [ ] No upstream production credentials or hardcoded publish IDs
- [ ] Git commit/tag matches deployed build

## End-to-end learning loop

- [ ] New user has **only dashed plus subject tile**
- [ ] PDF and text import works with recovery statuses
- [ ] Mixed subject classification editable and approved
- [ ] Subject avatar/name persisted
- [ ] Valid curriculum path and half-width right drawer
- [ ] Four actual education widgets in functional lesson canvas
- [ ] Current source references and objective definitions accessible
- [ ] Wrong answer recorded, grounded feedback generated
- [ ] Relevant reviewed remediation added to canvas
- [ ] Lesson progress persisted across refresh/reopen
- [ ] AI tutor respects context and private-source scope

## Shared space and rewards

- [ ] One shared room with two distinct live users and working chat/cursors
- [ ] Chat→note preservation, user attribution, no unauthorized access
- [ ] XP/trophy server-confirmed, duplicate attempts rejected

## Reliability and safety

- [ ] `npm run build` and types/tests clean
- [ ] Permission/unauthorized-source tests pass
- [ ] Failed source parsing/model outage recoverable
- [ ] Keyboard/escape/drawer focus and readable mobile state
- [ ] No invented citations or fake API/live behavior
- [ ] Usage caps, secrets and rate limits configured
- [ ] All major flows pass in deployed preview/incognito

## Demo and judging evidence

- [ ] Event participation/track verified with organizer
- [ ] Submission deadline/timezone checked on official listing
- [ ] Video rendered to applicable time/format
- [ ] Clear 1-sentence differentiation and compelling hook
- [ ] Real model requests, evaluation evidence and source references ready
- [ ] Clearly labeled precomputed/demo fixtures if used
- [ ] README, LICENSE, architecture diagram, originality notes
- [ ] Working deployment URL, repository URL and submission portal fields tested
- [ ] Final submission receipt saved

> Do not mark checks as complete in the docs without actually verifying them.
